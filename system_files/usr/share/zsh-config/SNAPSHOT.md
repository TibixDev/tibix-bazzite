# Snapshot provenance

This directory is a vendored snapshot of the Zsh configuration previously
installed by `ublue-hdkv-tibix`.

- Source: <https://github.com/fat0troll/zsh-config/tree/hdkv/ublue-hdkv>
- Commit: `d75f129cc21f56fae4d03f14ee889180fb3e1189`
- Commit date: 2025-01-03
- Snapshot date: 2026-08-18

It is deliberately stored in this repository instead of cloned during the
image build. Builds therefore remain reproducible if the source repository or
branch changes or disappears.
